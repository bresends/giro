# Entregas

Esta pasta recebe resumos de iniciativas concluídas. Use a data de conclusão no nome:

```text
AAAA-MM-DD-nome-da-entrega.md
```

Cada resumo deve registrar:

- objetivo e resultado;
- principais mudanças;
- validações executadas;
- decisões relevantes preservadas do plano;
- pendências ou limitações conhecidas.

Depois de criar e revisar o resumo, remova o plano operacional correspondente de `docs/planos/` e atualize `docs/00-painel.md`.
